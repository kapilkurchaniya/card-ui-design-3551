 # Card UI Design

A modern and responsive Card UI project built using React and Vite.  
This project contains reusable UI card components with clean design, responsive layout, and modern styling.

---

## 🚀 Features

- Responsive Card UI
- Reusable Components
- Modern Design
- Fast Development with Vite
- Clean Folder Structure
- Beginner Friendly Project

---

## 🛠️ Tech Stack

- React.js
- Vite
- CSS3
- JavaScript (JSX)

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/kapilkurchaniya/card-ui-design-3551.git
```

Go to project folder:

```bash
cd card-ui-design-3551/class0
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

## 🌐 Build for Production

```bash
npm run build
```
